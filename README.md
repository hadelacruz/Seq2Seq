## Descripción del Proyecto

Este proyecto implementa una arquitectura **Seq2Seq (Encoder-Decoder) basada en LSTMs** construida completamente desde cero utilizando PyTorch. El objetivo es traducir secuencias del inglés al español, manejando las variaciones naturales de longitud entre ambos idiomas.


## Arquitectura y Pipeline

El pipeline implementado sigue la estructura clásica de un modelo de traducción automática
